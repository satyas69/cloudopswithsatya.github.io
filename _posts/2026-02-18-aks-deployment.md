## 🏗️ Architecture Overview

This project demonstrates deploying a .NET microservices app to AKS using Terraform and Azure DevOps.

### 🔹 Tools Used
- Azure Kubernetes Service (AKS)
- Azure Container Registry (ACR)
- Terraform
- Azure DevOps Pipelines
- Docker
- Helm

## 🚀 Execution Steps

1. Provisioned ACR using Terraform
2. Created AKS cluster
3. Configured Service Principal
4. Built Docker image
5. Pushed image to ACR
6. Deployed via Helm
7. Implemented monitoring
